# Changelog

All notable changes to NinjaReviews will be documented in this file.

The project is currently in an early public release stage, so the changelog may evolve as the release and versioning process becomes more formal.

## Unreleased

- Initial public open-source repository preparation.
- Community contribution workflow and security reporting documentation.

## 1.0.0

- Self-hosted NinjaReviews widget.
- Google Places API (New) integration.
- Installer for configuring Google API access and selecting a place from a Google Maps URL.
- Server-side handling of the Google API key.
- Responsive review slider with mobile touch/swipe support.
- Standalone vanilla JavaScript frontend.
- Namespaced widget styling.
- Security hardening for installer and API endpoint.
